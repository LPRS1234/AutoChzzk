# AutoChzzk

현재 버전: **2.1.0**

## 2.1.0 확장 프로그램 자동 적용

앱 업데이트가 설치 폴더의 확장 프로그램 파일을 교체하면, 연결된 확장 프로그램이 새 파일을 자동으로 다시 불러옵니다. 이 기능을 처음 추가한 2.1.0으로 바꿀 때는 기존 2.0.0 확장 프로그램이 자동 적용 명령을 모르므로 `chrome://extensions`에서 AutoChzzk 확장 프로그램의 새로고침 버튼을 한 번 눌러야 합니다. 이후 버전부터는 연결된 상태라면 자동으로 적용됩니다.

## 2.0.0으로 전환

2.0.0은 로컬 연결 인증을 추가하여 이전 확장 프로그램과 호환되지 않습니다. 앱과 `chrome_extension`을 함께 업데이트하고, Chrome에서 확장 프로그램을 새로고침한 뒤 앱의 **확장 연결 코드**를 확장 프로그램 설정에 한 번 등록하세요. 각 Chrome 프로필에서 처음 연결할 때 등록이 필요합니다. 저장한 채널과 기존 설정 형식은 유지됩니다.

연결 코드는 비밀번호처럼 취급하세요. 앱은 코드를 사용자별 로컬 데이터 폴더에서 관리하며 네트워크로 코드 자체를 보내지 않습니다. 계정 식별값과 방송 상태는 연결 상대 확인 후 로컬로 전달합니다.

## 개발 및 검증

Windows 64비트 CPython **3.13.14**를 기준으로 의존성을 고정했습니다. 새 가상환경에서 다음 명령을 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-build.txt
.\.venv\Scripts\python -B -m unittest discover -s tests -v
node --test tests/*.test.js
.\.venv\Scripts\python -m PyInstaller AutoChzzk.spec
```

JavaScript 테스트에는 Node.js 24를 사용합니다. 빌드된 EXE는 `dist/AutoChzzk`에 생성되며, 런타임 로고 이미지도 포함합니다. 설치 파일은 Inno Setup 6에서 `installer/AutoChzzk.iss`로 별도 빌드합니다. 기존 빌드 결과를 보존하려면 PyInstaller의 `--distpath`와 `--workpath`, Inno Setup의 `MyOutputDir`를 새 디렉터리로 지정하세요. 빌드만으로 GitHub Release가 생성되거나 배포되지는 않습니다.

고정 버전은 검증 환경을 재현하기 위한 값입니다. 의존성을 업데이트할 때는 위 테스트와 Windows 빌드를 다시 검증한 뒤 런타임·빌드 요구사항을 함께 갱신합니다.

## 업데이트

앱은 실행할 때와 실행 중 6시간마다 GitHub Releases에 게시된 최신 설치 버전을 확인합니다. 새 버전의 Setup 파일을 백그라운드에서 다운로드하고 SHA-256 검증을 마치면 앱 안에 업데이트 버튼이 표시됩니다. 업데이트를 누르고 Windows 관리자 권한 요청을 승인하면 기존 앱 위에 자동으로 설치한 뒤 새 버전을 다시 실행합니다. 소스 코드만 GitHub에 올리는 것으로는 업데이트가 시작되지 않으며, 버전과 이름이 일치하는 Setup 파일을 GitHub Release에 첨부해야 합니다.

특정 치지직 채널의 방송 시작을 감지하면 Chrome 백그라운드 탭에서 해당 방송을 여는 Windows용 프로그램입니다. 자동 열기 기능에는 함께 제공되는 Chrome 확장 프로그램이 필요합니다.

## 실행

`run_autochzzk.bat`을 더블클릭하거나, 해당 폴더에서 아래 명령을 실행합니다.

```powershell
python .\autochzzk.py
```

Python 3와 트레이 아이콘용 패키지가 필요합니다. 치지직 로그인이나 API 키는 필요하지 않습니다. 처음 한 번, 폴더에서 아래 명령을 실행해 주세요.

```powershell
python -m pip install -r requirements.txt
```

## 사용법

1. 치지직 채널 URL 또는 32자리 채널 ID를 입력하고 **등록**을 누릅니다.
2. 등록 채널 목록에서 각 채널의 **감지 ON/OFF** 버튼으로 개별 감지 여부를 바꿉니다.
3. 각 등록 채널의 목록에서 확인 간격을 수정합니다. 과도한 요청을 피하기 위해 최소 15초입니다.
4. Chrome 확장 프로그램이 연결된 상태에서 감지가 켜진 채널이 방송을 시작하면 Chrome이 해당 방송을 비활성 새 탭으로 엽니다.

등록하면 감지는 자동으로 ON이 되며, 해당 채널을 즉시 한 번 확인합니다. 등록 목록과 감지 ON/OFF 설정은 자동 저장됩니다. 개발용 Python 실행에서는 프로그램 폴더의 `channels.json`에, 배포용 EXE에서는 `%LOCALAPPDATA%\AutoChzzk\channels.json`에 저장됩니다. 프로그램을 종료하거나 다시 실행해도 유지됩니다. 앱을 다시 실행하면 저장된 모든 채널의 방송 상태를 즉시 한 번씩 확인하며, Chrome 확장 프로그램이 연결되어 있고 감지 ON인 채널이 방송 중이면 바로 한 번 엽니다. 확장 프로그램이 설치되지 않았거나 연결되지 않은 경우에는 방송을 자동으로 열지 않습니다.

목록에는 채널 ID 대신 현재 방송 상태가 표시됩니다. 방송 중이면 제목이, 오프라인이면 `현재 방송 중이 아닙니다.`가 나타납니다.

창의 `X` 버튼을 누르면 프로그램이 종료되지 않고 시스템 트레이로 숨겨집니다. 창 상단의 **종료** 버튼 또는 트레이 아이콘의 **종료**를 선택하면 감지 프로그램을 완전히 끝냅니다.

## Chrome 확장 프로그램 설치 및 이미 보고 있는 방송 열기 방지

`chrome_extension` 폴더의 안내에 따라 **AutoChzzk Chrome Companion** 확장 프로그램을 설치해야 자동 열기가 동작합니다. 앱 상단의 **사용할 Chrome 프로필**에서 하나를 선택하세요. 선택한 프로필에만 확장 프로그램을 설치하면 되고, 다른 프로필에서 보고 있는 방송과 자동 접속은 앱이 무시합니다. 확장 프로그램이 없거나 연결되지 않은 상태에서는 AutoChzzk가 어떤 방송도 자동으로 열지 않습니다. 열린 방송 URL과 Chrome 프로필의 기본 계정 식별값만 로컬 앱(`127.0.0.1`)에 전달하며, 외부 서버와 통신하지 않습니다.
