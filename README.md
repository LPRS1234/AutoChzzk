# AutoChzzk

특정 치지직 채널의 방송 시작을 감지하면 기본 브라우저에서 해당 채널을 여는 Windows용 프로그램입니다.

## 실행

`run_autochzzk.bat`을 더블클릭하거나, 해당 폴더에서 아래 명령을 실행합니다.

```powershell
python .\autochzzk.py
```

Python 3와 트레이 아이콘용 패키지가 필요합니다. 치지직 로그인이나 API 키는 필요하지 않습니다. 처음 한 번, 폴더에서 아래 명령을 실행해 주세요.

```powershell
python -m pip install -r requirements.txt
```

## 사용법

1. 치지직 채널 URL 또는 32자리 채널 ID를 입력하고 **등록**을 누릅니다.
2. 등록 채널 목록에서 각 채널의 **감지 ON/OFF** 버튼으로 개별 감지 여부를 바꿉니다.
3. 각 등록 채널의 목록에서 확인 간격을 수정합니다. 과도한 요청을 피하기 위해 최소 15초입니다.
4. 감지가 켜진 채널이 방송을 시작하면 브라우저가 해당 방송을 새 탭으로 엽니다.

등록하면 감지는 자동으로 ON이 되며, 해당 채널을 즉시 한 번 확인합니다. 등록 목록과 감지 ON/OFF 설정은 같은 폴더의 `channels.json`에 자동 저장됩니다. 프로그램을 종료하거나 다시 실행해도 유지됩니다. 앱을 다시 실행하면 저장된 모든 채널의 방송 상태를 즉시 한 번씩 확인하며, 감지 ON인 채널이 방송 중이면 바로 한 번 엽니다. 같은 방송을 반복해서 열지는 않으며 채널 홈이 아니라 방송 시청 화면을 직접 엽니다.

목록에는 채널 ID 대신 현재 방송 상태가 표시됩니다. 방송 중이면 제목이, 오프라인이면 `현재 방송 중이 아닙니다.`가 나타납니다.

창의 `X` 버튼을 누르면 프로그램이 종료되지 않고 시스템 트레이로 숨겨집니다. 창 상단의 **종료** 버튼 또는 트레이 아이콘의 **종료**를 선택하면 감지 프로그램을 완전히 끝냅니다.

## Chrome에서 이미 보고 있는 방송 열기 방지

`chrome_extension` 폴더의 안내에 따라 **AutoChzzk Chrome Companion** 확장 프로그램을 설치하면, Chrome에 이미 열려 있는 치지직 방송과 같은 채널은 AutoChzzk가 새 탭으로 열지 않습니다. 확장 프로그램은 열린 방송 URL에서 채널 ID만 읽어 로컬 앱(`127.0.0.1`)에 전달하며 외부 서버와 통신하지 않습니다. 앱 시작 직후에는 확장 프로그램의 탭 상태를 받기 위해 최대 약 32초 동안 방송 페이지 열기를 기다립니다.
