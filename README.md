# AutoChzzk

현재 버전: **2.4.0**

## 2.4.0 전체 갱신으로 방송 다시 열기

**전체 갱신**을 누르면 감지 ON인 채널의 방송 상태를 다시 확인하고, 진행 중인 방송의 탭이 없으면 다시 엽니다. 이미 열린 방송 탭은 중복으로 열지 않습니다. 감지 OFF인 채널은 방송 상태만 갱신하며, 조회에 실패하면 이전 방송 상태를 보존하고 다음 정상 확인에서 재열기를 다시 판단합니다. 일반 자동 감지와 채널별 **지금 확인**의 동작은 유지합니다.

## 2.3.0 버전 옆 업데이트 버튼

새 버전이 확인되면 메인 화면 하단의 버전 표시와 앱 종료 사이에 **업데이트** 버튼이 나타납니다. 버튼을 누르면 설치 파일을 다운로드·검증한 뒤 설치 안내를 표시합니다. 다운로드 중에는 중복 클릭을 막고, **나중에**를 선택하거나 다운로드에 실패해도 같은 버튼으로 다시 시도할 수 있습니다.

## 2.2.2 채널 안내 문구 정렬

채널 이름, 방송 상태와 마지막 확인 시간의 왼쪽 여백을 통일하고, 방송 상태 문구의 첫 글자가 잘리지 않도록 수정했습니다.

## 2.2.1 감지 쉬기 버튼 제거

기본 화면의 **30분 쉬기 / 1시간 쉬기 / 다시 시작** 버튼을 제거했습니다. **전체 갱신**, 채널별 마지막 정상 확인과 확인 실패 표시, **⋯ → 지금 확인**, 앱 내부 설정 팝업은 유지합니다. 자동 감지는 각 채널의 ON/OFF 스위치로 설정합니다.

## 2.2.0 확인 상태와 감지 일시정지

채널마다 마지막으로 방송 상태를 정상 확인한 시간을 표시합니다. 조회에 실패하면 이전 방송 상태를 보존하고 **확인 실패**를 표시하며, 다음 조회가 성공하면 해제합니다. **전체 갱신**은 감지 OFF 채널을 포함한 등록 채널을 모두 다시 확인합니다. 채널의 **⋯ → 지금 확인**으로 하나만 갱신할 수도 있습니다. 조회는 최대 4개씩 진행하며, 갱신 중 다시 눌러도 같은 채널을 중복 조회하지 않습니다.

2.2.0에서 제공한 **30분 쉬기 / 1시간 쉬기 / 다시 시작** 버튼은 2.2.1부터 화면에서 제거했습니다.

**설정**은 별도 Windows 창 대신 메인 창 내부에서 열립니다. 작은 창에서는 설정 내용을 스크롤할 수 있으며, **닫기** 또는 Esc로 메인 화면으로 돌아갑니다.

## 2.1.9 종료 버튼과 채널 메뉴

**앱 종료** 버튼을 기본 화면 하단 오른쪽으로 옮겼습니다. 채널의 **⋯** 메뉴는 앱 색상에 맞춘 얇은 테두리와 여백, 읽기 쉬운 글자로 정리했습니다. 현재 확인 간격을 위쪽에 표시하고, 아래에서 간격 수정 또는 채널 삭제를 선택할 수 있습니다. 메뉴 밖 클릭이나 Esc로 닫을 수 있고 키보드로도 항목을 선택할 수 있습니다.

## 2.1.8 UI 표시 수정

작업 상태 안내 문구를 초록색 점 옆에 왼쪽 정렬했습니다. 감지 ON/OFF 스위치의 둥근 가장자리를 부드럽게 표시하도록 수정했으며, 기존 슬라이드 모션은 유지합니다.

## 2.1.7 목록 중심 UI와 감지 스위치

기존 색상 테마를 유지하고 채널 목록이 메인 화면의 중심이 되도록 정리했습니다. **채널 추가**에서 URL 또는 ID를 등록하고, 각 채널의 **ON/OFF 스위치**로 감지를 전환합니다. 스위치 손잡이와 배경은 약 0.16초 동안 부드럽게 바뀌며, 설정을 저장하지 못하면 기존 상태를 유지합니다. **⋯** 메뉴에서 현재 확인 간격을 확인하고 간격 수정 또는 삭제를 선택할 수 있습니다. Chrome 프로필, 확장 프로그램 연결·설치·연결 코드와 업데이트 내역은 **설정** 창에서 확인할 수 있습니다.

## 2.1.6 시작 시 Chrome 중복 창 수정

앱 시작 시 여러 채널이 방송 중이어도 Chrome 실행 요청을 공유하여 창이 여러 개 열리지 않도록 수정했습니다. 확장 프로그램의 탭 보고를 기다린 뒤 복원된 방송 탭은 건너뛰고, 새 방송만 기존 Chrome 창의 백그라운드 탭으로 엽니다. 연결 확인이 늦거나 실패하더라도 실행 중인 Chrome을 반복해서 열지 않습니다.

## 2.1.5 채널 감지 전환 개선

채널의 감지 ON/OFF를 변경할 때 해당 버튼과 감지 중인 채널 수만 갱신합니다. 목록 깜빡임과 스크롤 위치 초기화를 방지하고, 입력 중인 확인 간격도 유지합니다.

## 2.1.4 채널 목록 표시 개선

방송 상태를 주기적으로 확인하거나 채널별 확인 간격을 수정할 때 목록 전체를 다시 만들지 않고, 바뀐 항목만 갱신하여 화면 깜빡임을 줄였습니다.

## 2.1.3 현재 탭 유지 개선

새 방송은 다시 백그라운드 탭으로 열려 사용자가 보고 있던 탭을 바꾸지 않습니다. AutoChzzk가 연 방송 탭에만 페이지 활성 신호와 음소거 재생 요청을 보내 치지직 플레이어를 시작합니다.

## 2.1.2 방송 탭 시작 개선

AutoChzzk가 새 방송 탭을 Chrome 안에서 바로 선택하여 치지직 플레이어 초기화를 시작합니다. 첫 자동재생 시도 시간이 지난 뒤 탭을 다시 선택해도 음소거 자동재생을 다시 시도합니다.

## 2.1.1 방송 자동재생 개선

AutoChzzk가 백그라운드로 연 방송 탭은 Chrome의 자동재생 제한을 피하기 위해 음소거 상태로 재생됩니다. 치지직 플레이어 로딩이 늦으면 최대 30초 동안 다시 시도합니다. 방송 소리를 들으려면 해당 탭에서 음소거를 해제하세요.

## 2.1.0 확장 프로그램 자동 적용

앱 업데이트가 설치 폴더의 확장 프로그램 파일을 교체하면, 연결된 확장 프로그램이 새 파일을 자동으로 다시 불러옵니다. 이 기능을 처음 추가한 2.1.0으로 바꿀 때는 기존 2.0.0 확장 프로그램이 자동 적용 명령을 모르므로 `chrome://extensions`에서 AutoChzzk 확장 프로그램의 새로고침 버튼을 한 번 눌러야 합니다. 이후 버전부터는 연결된 상태라면 자동으로 적용됩니다.

## 2.0.0으로 전환

2.0.0은 로컬 연결 인증을 추가하여 이전 확장 프로그램과 호환되지 않습니다. 앱과 `chrome_extension`을 함께 업데이트하고, Chrome에서 확장 프로그램을 새로고침한 뒤 앱의 **설정 → 연결 코드**를 확장 프로그램 설정에 한 번 등록하세요. 각 Chrome 프로필에서 처음 연결할 때 등록이 필요합니다. 저장한 채널과 기존 설정 형식은 유지됩니다.

연결 코드는 비밀번호처럼 취급하세요. 앱은 코드를 사용자별 로컬 데이터 폴더에서 관리하며 네트워크로 코드 자체를 보내지 않습니다. 계정 식별값과 방송 상태는 연결 상대 확인 후 로컬로 전달합니다.

## 개발 및 검증

Windows 64비트 CPython **3.13.14**를 기준으로 의존성을 고정했습니다. 새 가상환경에서 다음 명령을 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-build.txt
.\.venv\Scripts\python -B -m unittest discover -s tests -v
node --test tests/*.test.js
.\.venv\Scripts\python -m PyInstaller AutoChzzk.spec
```

JavaScript 테스트에는 Node.js 24를 사용합니다. 빌드된 EXE는 `dist/AutoChzzk`에 생성되며, 런타임 로고 이미지도 포함합니다. 설치 파일은 Inno Setup 6에서 `installer/AutoChzzk.iss`로 별도 빌드합니다. 기존 빌드 결과를 보존하려면 PyInstaller의 `--distpath`와 `--workpath`, Inno Setup의 `MyOutputDir`를 새 디렉터리로 지정하세요. 빌드만으로 GitHub Release가 생성되거나 배포되지는 않습니다.

고정 버전은 검증 환경을 재현하기 위한 값입니다. 의존성을 업데이트할 때는 위 테스트와 Windows 빌드를 다시 검증한 뒤 런타임·빌드 요구사항을 함께 갱신합니다.

## 업데이트

앱은 실행할 때와 실행 중 6시간마다 GitHub Releases에 게시된 최신 설치 버전을 확인합니다. 새 버전의 설치 파일 정보가 확인되면 하단 버전 표시 옆에 **업데이트** 버튼이 나타납니다. 버튼을 누르면 Setup 파일을 백그라운드에서 다운로드하고 크기와 SHA-256을 검증한 뒤 설치 안내를 표시합니다. 안내에서 업데이트를 누르고 Windows 관리자 권한 요청을 승인하면 기존 앱 위에 자동으로 설치한 뒤 새 버전을 다시 실행합니다. **나중에**를 선택해도 하단 버튼으로 다시 설치 안내를 열 수 있습니다. 소스 코드만 GitHub에 올리는 것으로는 업데이트가 시작되지 않으며, 버전과 이름이 일치하는 Setup 파일을 GitHub Release에 첨부해야 합니다.

특정 치지직 채널의 방송 시작을 감지하면 Chrome 백그라운드 탭에서 해당 방송을 여는 Windows용 프로그램입니다. 자동 열기 기능에는 함께 제공되는 Chrome 확장 프로그램이 필요합니다.

## 실행

`run_autochzzk.bat`을 더블클릭하거나, 해당 폴더에서 아래 명령을 실행합니다.

```powershell
python .\autochzzk.py
```

Python 3와 트레이 아이콘용 패키지가 필요합니다. 치지직 로그인이나 API 키는 필요하지 않습니다. 처음 한 번, 폴더에서 아래 명령을 실행해 주세요.

```powershell
python -m pip install -r requirements.txt
```

## 사용법

1. 메인 화면의 **채널 추가**를 누른 뒤 치지직 채널 URL 또는 32자리 채널 ID를 입력하고 **등록**을 누릅니다.
2. 등록 채널 목록에서 각 채널의 **ON/OFF 스위치**로 개별 감지 여부를 바꿉니다.
3. 각 채널의 **⋯** 메뉴에서 **확인 간격 수정**을 선택합니다. 과도한 요청을 피하기 위해 최소 15초입니다.
4. Chrome 확장 프로그램이 연결된 상태에서 감지가 켜진 채널이 방송을 시작하면 Chrome이 해당 방송을 백그라운드 새 탭으로 열며, 현재 보고 있던 탭은 유지합니다.

등록하면 감지는 자동으로 ON이 되며, 해당 채널을 즉시 한 번 확인합니다. 등록 목록과 감지 ON/OFF 설정은 자동 저장됩니다. 개발용 Python 실행에서는 프로그램 폴더의 `channels.json`에, 배포용 EXE에서는 `%LOCALAPPDATA%\AutoChzzk\channels.json`에 저장됩니다. 프로그램을 종료하거나 다시 실행해도 유지됩니다. 앱을 다시 실행하면 저장된 모든 채널의 방송 상태를 즉시 한 번씩 확인하며, Chrome 확장 프로그램이 연결되어 있고 감지 ON인 채널이 방송 중이면 바로 한 번 엽니다. 확장 프로그램이 설치되지 않았거나 연결되지 않은 경우에는 방송을 자동으로 열지 않습니다.

목록에는 채널 ID 대신 현재 방송 상태가 표시됩니다. 방송 중이면 제목이, 오프라인이면 `현재 방송 중이 아닙니다.`가 나타납니다.

창의 `X` 버튼을 누르면 프로그램이 종료되지 않고 시스템 트레이로 숨겨집니다. 기본 화면 하단의 **앱 종료** 또는 트레이 아이콘의 **종료**를 선택하면 감지 프로그램을 완전히 끝냅니다.

## Chrome 확장 프로그램 설치 및 이미 보고 있는 방송 열기 방지

`chrome_extension` 폴더의 안내에 따라 **AutoChzzk Chrome Companion** 확장 프로그램을 설치해야 자동 열기가 동작합니다. 앱의 **설정 → 사용할 Chrome 프로필**에서 하나를 선택하고 **적용**을 누르세요. 프로필이 하나뿐이면 현재 프로필 이름만 표시합니다. 선택한 프로필에만 확장 프로그램을 설치하면 되고, 다른 프로필에서 보고 있는 방송과 자동 접속은 앱이 무시합니다. 확장 프로그램이 없거나 연결되지 않은 상태에서는 AutoChzzk가 어떤 방송도 자동으로 열지 않습니다. 열린 방송 URL과 Chrome 프로필의 기본 계정 식별값만 로컬 앱(`127.0.0.1`)에 전달하며, 외부 서버와 통신하지 않습니다.
