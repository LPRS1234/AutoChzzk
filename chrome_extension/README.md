# AutoChzzk Chrome Companion 설치

이 확장 프로그램은 Chrome에 열려 있는 치지직 **방송 시청 페이지**의 채널 ID만 AutoChzzk 앱으로 전달합니다. 외부 서버로 정보를 보내지 않으며, 통신 대상은 내 컴퓨터의 `127.0.0.1:8765`뿐입니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 화면 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `chrome_extension` 폴더를 선택합니다.
5. AutoChzzk를 실행한 상태로 둡니다.

Chrome 프로필을 여러 개 사용한다면, 앱 상단의 **사용할 Chrome 프로필**에서 선택한 프로필에만 위 과정을 진행하면 됩니다. 선택하지 않은 프로필의 확장 프로그램과 방송 시청 상태는 앱이 무시합니다. 확장 프로그램은 선택된 Chrome 프로필의 기본 계정 식별값을 로컬 앱에 전달해 올바른 프로필만 구분하며, 외부 서버와 통신하지 않습니다.

코드를 업데이트한 뒤에는 `chrome://extensions`에서 확장 프로그램의 **새로고침** 버튼을 한 번 누르세요. 이미 열려 있던 치지직 방송 탭은 한 번 새로고침하거나 다시 열어 이전 확장 프로그램 스크립트를 정리해 주세요.

설치 후에는 치지직 방송을 Chrome에서 보고 있을 때, AutoChzzk가 같은 채널 방송을 새 탭으로 열지 않습니다. Chrome이 실행 중이지만 다른 프로그램을 사용 중일 때 새 방송이 감지되면, 방송은 Chrome의 **백그라운드 탭**으로 열려 현재 작업 창을 앞으로 덮지 않습니다. Chrome이 꺼져 있으면 일반 방식으로 Chrome을 열어 방송을 표시합니다.
