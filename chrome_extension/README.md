# AutoChzzk Chrome Companion 설치

이 확장 프로그램은 Chrome에 열려 있는 치지직 **방송 시청 페이지**의 채널 ID, Chrome 프로필의 계정 식별값, 창 선택 상태와 명령 완료 상태를 AutoChzzk 앱으로 전달합니다. 외부 서버로 정보를 보내지 않으며, 통신 대상은 내 컴퓨터의 `127.0.0.1:8765`뿐입니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 화면 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `chrome_extension` 폴더를 선택합니다.
5. AutoChzzk를 실행한 상태로 둡니다.
6. 앱의 **확장 연결 코드** 버튼에서 코드를 복사합니다.
7. Chrome 도구 모음의 AutoChzzk 확장 아이콘을 누르거나 확장 프로그램 세부정보의 **확장 프로그램 옵션**을 엽니다.
8. 연결 코드를 붙여 넣고 **연결 코드 저장**을 누른 뒤 앱에서 연결 상태를 확인합니다.

2.0.0부터 앱과 확장 프로그램 모두 2.0.0 이상으로 업데이트하고 처음 한 번 연결 코드를 등록해야 합니다. 이전 버전과는 연결되지 않습니다. 사용하는 Chrome 프로필마다 코드를 등록해 주세요. 코드는 다른 사람이나 웹페이지에 공유하지 마세요. 앱은 코드를 Windows 사용자별 보호 기능(DPAPI)으로 `%LOCALAPPDATA%\AutoChzzk\extension_pairing.key`에 보관합니다. 파일이 손상되면 자동으로 덮어쓰지 않습니다.

확장 프로그램은 계정 정보를 보내기 전에 앱의 인증 응답을 확인하고, 요청과 응답의 서명을 검증합니다. 코드는 HTTP로 전송되지 않습니다. 이 보호는 같은 Windows 사용자 권한으로 앱이나 Chrome 저장소를 읽는 프로그램까지 차단하는 장치는 아닙니다.

Chrome 프로필을 여러 개 사용한다면, 앱 상단의 **사용할 Chrome 프로필**에서 선택한 프로필에만 위 과정을 진행하면 됩니다. 선택하지 않은 프로필의 확장 프로그램과 방송 시청 상태는 앱이 무시합니다. 확장 프로그램은 선택된 Chrome 프로필의 기본 계정 식별값을 로컬 앱에 전달해 올바른 프로필만 구분하며, 외부 서버와 통신하지 않습니다.

코드를 업데이트한 뒤에는 `chrome://extensions`에서 확장 프로그램의 **새로고침** 버튼을 한 번 누르세요. 이미 열려 있던 치지직 방송 탭은 한 번 새로고침하거나 다시 열어 이전 확장 프로그램 스크립트를 정리해 주세요.

설치 후에는 치지직 방송을 Chrome에서 보고 있을 때, AutoChzzk가 같은 채널 방송을 새 탭으로 열지 않습니다. Chrome이 실행 중이지만 다른 프로그램을 사용 중일 때 새 방송이 감지되면, 방송은 Chrome의 **백그라운드 탭**으로 열려 현재 작업 창을 앞으로 덮지 않습니다. Chrome이 꺼져 있으면 선택한 프로필로 Chrome을 실행하고, 확장 프로그램의 인증 연결을 기다린 뒤 방송 탭을 엽니다. 제한 시간 안에 연결되지 않으면 앱에서 연결 상태를 확인해 주세요.
